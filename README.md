# Pretty Tanks

2D-игра на Unity, в которой игрок управляет танком и сопровождает
фургон с тремя котятами до дома.

Фургон движется самостоятельно. Игрок защищает его от врагов,
использует усиления, следит за боезапасом и ремонтирует фургон,
временно жертвуя работоспособностью одной из систем своего танка.

## Запуск проекта в Unity

### Что понадобится

- Windows или macOS.
- Unity Hub.
- Версия Unity 6.6.
- Интернет при первом открытии для загрузки необходимых пакетов.

### Пошаговая инструкция

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Полностью распакуйте архив.
3. Откройте Unity Hub.
4. В разделе **Projects** выберите добавление существующего проекта с диска — **Add / Add project from disk**.
5. Укажите папку, внутри которой находятся:
   - `Assets`
   - `Packages`
   - `ProjectSettings`
6. Откройте проект в версии Unity 6.6.
7. Дождитесь завершения импорта ресурсов, установки пакетов и компиляции скриптов. Первое открытие может занять несколько минут.
8. В окне **Project** откройте сцену:
   `Assets/Scenes/Main.unity`.
9. Нажмите кнопку **Play** в верхней части редактора.
10. В главном меню выберите доступный уровень и нажмите **«Отправиться в путь»**.

При первом начале игры автоматически показываются комикс и инструкция. В дальнейшем инструкцию можно открыть кнопкой **«Как играть»** в главном меню.

## Цель игры

Доставьте фургон с котятами до конца маршрута, сохранив и фургон, и собственный танк.

- **Победа:** фургон добрался до дома.
- **Поражение:** уничтожен фургон или танк игрока.
- После завершения попытки можно начать уровень заново.
- Прохождение уровня открывает следующий.
- Доступ к открытым уровням сохраняется автоматически.

Уничтожать всех противников для победы необязательно: главная задача — защитить конвой.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD или стрелки |
| Прицеливание | Движение мыши |
| Стрельба | Левая кнопка мыши, можно удерживать |
| Начать ремонт фургона | E рядом с фургоном |
| Использовать подобранную бомбу | Пробел |
| Пауза / продолжение | Esc |

Для управления из редактора сначала щёлкните внутри окна **Game**,
чтобы оно получило фокус.

## Стрельба и боезапас

Запас патронов игрока ограничен и автоматически восстанавливается со временем. Отдельные ящики с патронами не требуются.

- Обычный выстрел расходует один патрон.
- Тройной выстрел расходует три патрона.
- Лазерный выстрел расходует один патрон.
- Во время паузы пополнение приостанавливается.

Обычные снаряды отражаются от стальных препятствий.
Количество рикошетов не ограничено, но у каждого снаряда есть ограниченное время жизни.

После первого рикошета собственный снаряд может повредить танк игрока.

Если одновременно активны лазер и тройной выстрел, оружие использует лазер.

## Ремонт фургона

Чтобы начать ремонт:

1. Подъедьте к повреждённому фургону.
2. Нажмите **E**.
3. Оставайтесь рядом до завершения ремонта.

Во время ремонта танк не может стрелять, а его движение ограничивается.

После успешного ремонта:

- восстанавливается часть здоровья фургона;
- временно отключается одна случайная система танка игрока;
- начинается задержка перед следующим ремонтом.

Если фургон окажется слишком далеко, ремонт прервётся.
Полностью исправный фургон ремонтировать нельзя.

## Модули танка

Помимо общего здоровья, у танка есть отдельные модули:

| Модуль | Последствия повреждения или отключения |
|---|---|
| Левая гусеница | Нарушается движение, корпус начинает разворачивать |
| Правая гусеница | Нарушается движение, корпус начинает разворачивать |
| Пушка | Стрельба становится недоступной |
| Башня | Свободное наведение башни становится недоступным |
| Двигатель | Снижается скорость или прекращается движение |

При отключении обеих гусениц танк не может двигаться.

Следите за состоянием модулей на нижней панели интерфейса.

## Подарки и усиления

Подарки появляются на карте. Для подбора нужно проехать по ним
танком игрока.

| Цвет подарка | Эффект |
|---|---|
| Розовый | Тройной выстрел: три снаряда веером |
| Фиолетовый | Лазер: луч поражает цели вдоль линии и проходит сквозь препятствия |
| Оранжевый | Бомба: нажмите Пробел для взрыва вокруг своего танка |
| Жёлтый | Временное ускорение танка |
| Голубой | Щит: временная защита от урона |
| Белый | Постепенное восстановление здоровья фургона |
| Мятный | Восстановление повреждённого модуля; если таких модулей нет — лечение танка |

Большинство усилений действует ограниченное время.
Повторный подбор однотипного временного усиления обновляет его таймер, не складывая длительности.

Бомбу нужно применить до окончания её таймера.
Ремонтный подарок срабатывает сразу.

Активный щит обозначается полупрозрачным пузырём вокруг танка.

## Противники

| Тип | Поведение |
|---|---|
| Скутер | Преследует фургон и наносит таранный урон |
| Снайпер | Атакует танк игрока с дистанции |
| Рикошетник | Ищет возможность выстрелить в фургон через отражение от стали |
| Танк-босс | Стреляет и создаёт небольших помощников |
| Призрак | Периодически переходит в фазу защиты и становится полупрозрачным |

Перед обычным появлением противника на карте показывается розовая предупреждающая метка.

Сложность увеличивается по мере прохождения: растут характеристики и количество противников, меняется темп появления и открываются новые типы врагов.

## Поверхности и препятствия

- **Сталь:** отражает обычные снаряды.
- **Кирпич:** разрушается от попаданий.
- **Дерево:** загорается; огонь может распространяться на соседние деревянные клетки.
- **Лёд:** после разрушения препятствия оставляет скользкую поверхность.
- **Обломки:** временно замедляют движение.

Фронтальная броня врагов уменьшает урон от попаданий спереди.
Используйте позиционирование и рикошеты для атак с других направлений.

## Уровни и сохранения

В игре шесть миссий с растущей сложностью.
Используются четыре базовые карты; поздние миссии повторно используют знакомые карты с более сложными условиями боя.

Локально сохраняются:

- доступ к открытым уровням;
- отметка о просмотре первого вступления.

Текущая незавершённая битва не сохраняется.

## Структура проекта

| Путь | Содержимое |
|---|---|
| `Assets/Scenes/Main.unity` | Стартовая сцена |
| `Assets/Scripts/Core` | Состояния игры, здоровье, сохранения и события |
| `Assets/Scripts/Tanks` | Управление, движение, оружие, снаряды и модули |
| `Assets/Scripts/Enemies` | Поведение противников |
| `Assets/Scripts/Truck` | Движение и ремонт фургона |
| `Assets/Scripts/Levels` | Создание карты, волны и появление подарков |
| `Assets/Scripts/PowerUps` | Усиления и подбор подарков |
| `Assets/Scripts/UI` | Главное меню, обучение и игровой интерфейс |
| `Assets/Scripts/Data` | Классы конфигураций |
| `Assets/Resources` | Загружаемые ресурсы и настройки |
| `Assets/Editor` | Инструменты настройки, проверки и сборки |
| `Packages` | Зависимости проекта |
| `ProjectSettings` | Настройки Unity |

Характеристики и параметры баланса хранятся в конфигурациях ScriptableObject. Игровые объекты используют эти настройки, а текущее здоровье, патроны и таймеры хранят отдельно.

## Если игра не запускается

### Кнопка Play недоступна или Unity сообщает об ошибках компиляции

Откройте **Window → General → Console** и посмотрите первую
красную ошибку. Убедитесь, что проект открыт в указанной версии Unity
и установка пакетов завершена.

### Вместо меню отображается пустая сцена

Откройте именно `Assets/Scenes/Main.unity`, затем нажмите Play.

### Управление не реагирует в редакторе

Щёлкните внутри окна Game. Проверьте, не включена ли пауза.

### Не отображаются картинки или отсутствует музыка

Проверьте, что архив полностью распакован и папка Assets
загружена целиком, вместе с файлами `.meta`.

### Комикс не появляется повторно

Это ожидаемое поведение после первого прохождения вступления.
Раздел «Как играть» остаётся доступным из главного меню.

### Windows-сборка не открывается

Распакуйте весь архив перед запуском. Не запускайте `.exe`
изнутри архива и не переносите его отдельно от остальных файлов.
